# Domain → Repository → Supabase Mapping

**Status label for this entire document: PROPOSED / CANDIDATE — not verified against a live schema.** As established in [DATABASE_SCHEMA.md](./DATABASE_SCHEMA.md), no live Supabase inspection has been performed and no migration exists in this repo. Every "Column" below is derived mechanically from the domain model field (camelCase → snake_case, per CLAUDE.md's "DATABASE NAMING" rule) — it is what a column _would plausibly be named if the frontend's domain shape were mirrored 1:1_, not a confirmed real column. Module 12A must validate every row of this table against the actual schema (via live inspection) before writing a single `Supabase*Repository`, and correct this document to match reality, not the other way around.

Format per entity: **Domain Model → Repository → Supabase Table → Columns**.
