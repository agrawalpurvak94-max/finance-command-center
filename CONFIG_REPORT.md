- **Bug encountered and fixed**: `shadcn init` initially failed with `Could not load the workspace config` on both `shadcn@4.16.0` and the suggested fallback `4.15.0`. Root cause (confirmed against shadcn's own Vite installation docs, not guessed): the current CLI requires the **root** `tsconfig.json` to carry `compilerOptions.baseUrl`/`paths` directly, not only the referenced `tsconfig.app.json`. The standard `create-vite` scaffold only puts the alias in `tsconfig.app.json`, which is what broke it. Fixed by adding the same `baseUrl`/`paths` block to the root `tsconfig.json`.
